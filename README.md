# Prime Intellect — pilots

1 working pilot built for Prime Intellect.

### Reward-hack harness

Four RL environments against a battery of trivial policies: doing literally nothing scores 16 of a possible 16.4 on one, and on another the reward is identical to the correct behaviour while only 5 of 12 tickets end up labelled right.

`companies/prime-intellect/prime-intellect-reward-hack-harness/`

## Running it

```bash
npm install
npm run dev
```

## Note on the data

Every figure in these pilots is synthetic and labelled as such in the interface.
Nothing here is connected to Prime Intellect's systems, and no number should be
read as a measurement of their business.
